Netwerken

Webwizz project

Voor dit project is een netwerk opgezet voor een bedrijf. Het project brengt de onderdelen van een bedrijfsnetwerk samen in een oplossing die aansluit bij de behoeften van de organisatie.

Focus van het project

Het ontwerpen en opbouwen van een netwerk en nadenken over hoe toestellen en gebruikers binnen een bedrijfsomgeving met elkaar kunnen communiceren.

Automatisering

Geautomatiseerd serverscript

Dit script maakt automatisch een virtuele server aan op basis van de specificaties die de gebruiker opgeeft. Zo worden terugkerende stappen bij het aanmaken van een server eenvoudiger.

Focus van het project

Gebruikersinvoer omzetten naar een geautomatiseerde taak en het aanmaken van virtuele servers afstemmen op verschillende specificaties.

Draadloze netwerken

Wifi voor de studentenkamer

In dit project wordt een extra toegangspunt gebruikt om het wifi-signaal in een studentenkamer uit te breiden tot op zolder.

Focus van het project

Een praktisch probleem met draadloze dekking aanpakken en zorgen dat een netwerk ook op een moeilijker bereikbare plek beschikbaar is.

Netwerkbeheer

Monitoring met grafieken

Dit project toont grafieken van het netwerkverkeer op één scherm, zodat de activiteit van het netwerk overzichtelijk kan worden opgevolgd.

Focus van het project

Netwerkgegevens visueel presenteren en een centraal overzicht maken dat helpt om netwerkverkeer te bekijken.
